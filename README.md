## ⚕️ Health Assistant Bot

### Диагностический Telegram-бот

Этот проект представляет собой **Telegram-бот**, предназначенный для проведения **предварительной самодиагностики** и получения рекомендаций.

---

## 🚀 Инструкция по Запуску

Чтобы подготовить и запустить проект, выполните следующие шаги:

### 1. Клонирование репозитория

```bash
git clone <URL_РЕПОЗИТОРИЯ>
cd HealthAssistant
```
### 2. Установка зависимостей

```bash
npm install
```

### 3. Настройка переменных окружения
Создайте файл .env в корневой папке проекта и добавьте Telegram-токен

### 4. Запуск приложения

```bash
npm start
```

## 🚀 Скрипты разработчика
